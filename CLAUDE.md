# Fly-Brain Drone

Two friends building, for fun, a small quadcopter steered by a simulated fruit fly brain. Ayham works with Claude; Ahmed (GitHub: AhmedDoesCS) works in KiCad 10 on the PCB and does not use Claude. This file is Claude's context. Keep it up to date when a decision changes.

## How it works

- The **brain** runs on a laptop: Shiu et al.'s whole-brain model (`philshiu/Drosophila_brain_model`, Brian2, FlyWire connectome v783, ~139k neurons). It is far too big for a microcontroller.
- The **drone** is an ESP32-S3 CAM board running ESP-Drone-style firmware that keeps it stable (MPU6050 + PID).
- Loop: drone camera (OV2640) → video over WiFi → laptop extracts features with OpenCV (looming, sideways motion, small targets) → stimulates matching neurons (LPLC2/LC4, HS cells, LC10) → reads descending neurons (DNa01/DNa02 steering, Giant Fiber escape) → sends yaw/climb/forward commands over WiFi (UDP) → ESP32 drives motors. Target 5–10 brain decisions per second.

## Decisions (don't revisit without a reason)

- FlyWire brain via Shiu's model. We decided **not** to use the male CNS connectome.
- WiFi for video and commands (ESP-NOW can't carry video).
- Feed the brain visual *features* first; a full fly-eye model (`flyvis`, `flygym`) is a later upgrade.
- **Through-hole parts only** — we have a hand soldering iron, no SMD rework.
- Budget is tight (~$43 spent); prefer cheap AliExpress "Choice" parts.
- The frame is a custom PCB (pcb/, generated by pcb/gen.py): X-shaped 2-layer board, top = parts + GND pour, bottom = VBAT plane + battery tray. Signals to the ESP32 end at labeled jumper pads because its pinout is unconfirmed. Regenerate and re-check after any change. Ahmed may edit pcb/kicad/fly-drone.kicad_pcb in KiCad; once he has, that file is the master copy (gen.py refuses to overwrite it) and changes should be made in KiCad, not gen.py.

## Hardware

See `docs/parts.md` and `docs/wiring.md`. Key points:
- Board: ESP32-S3 N16R8 CAM dev board (DIY NOW), OV2640 on the 24-pin DVP connector.
- Power: 1S 500 mAh battery → motors directly; → TPS63020 buck-boost → 3.3 V to the ESP32 **3V3 pin** (not 5V). Unplug the battery when USB is connected.
- Motors: 4× 8520 coreless, each switched low-side by an IRLB8721 MOSFET, 1N5819 flyback diode across the motor, 10 kΩ gate pull-down.
- PlatformIO for the ESP32-S3 needs PSRAM enabled: `board_build.arduino.memory_type = qio_opi`, `board_build.flash_size = 16MB`, `-DBOARD_HAS_PSRAM`.
